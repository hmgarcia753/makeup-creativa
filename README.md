# Makeup Creativa - Aplicación Web de Reservas

Proyecto React + Vite + Tailwind CSS conectado a **Firebase Firestore** y **Cloudinary**.

## Cómo publicar en Vercel:
1. Sube todos estos archivos (manteniendo la carpeta `src`) a tu repositorio de GitHub (`makeup-creativa`).
2. Entra a [vercel.com](https://vercel.com), selecciona tu repositorio `makeup-creativa` y haz clic en **Deploy**.
3. ¡Listo! Vercel te entregará tu enlace público HTTPS.
